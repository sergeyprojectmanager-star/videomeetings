# video-meetings

Monorepo (npm workspaces).

| Project | Stack   | Path       |
| ------- | ------- | ---------- |
| `web`   | Next.js | `apps/web` |
| `api`   | NestJS  | `apps/api` |

## Getting started

```sh
npm install
npm run dev        # web + api in parallel
```

## Scripts (from the root)

- `npm run dev` / `dev:web` / `dev:api`
- `npm run build`
- `npm run lint` / `lint:fix`
- `npm run typecheck`
- `npm run test`
- `npm run format` / `format:check`
